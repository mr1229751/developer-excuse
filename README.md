One developer excuse, 121 characters: "it works on my machine" turned literal — the machine was shipped to the customer this morning, so the fix is in transit. A tiny Node program writes that single line to the entry file, guarding the gate itself: 1–200 characters, one line, never only whitespace. The line was picked by criteria critique over six rivals for turning the most worn excuse in the canon in a way nobody has before.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
